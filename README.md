# Symphony-of-Lights
An Arduino-based music-synced LED controller using logic circuits and switching theory to generate interactive visual light patterns.

About the Project
Symphony of Lights is an interactive embedded systems project that synchronizes dynamic LED lighting patterns with audio rhythm. Built using an Arduino, the project applies concepts from microprocessor systems, logic design, and switching theory to process manual control inputs and coordinate multi-channel visual outputs.

Key Features
Dynamic rhythm and beat synchronization for audio-responsive lighting

8-channel LED output array configured for multiple pattern variations

4-switch input interface for manual control and state toggling

Hardware-level integration of debouncing and switching logic

Hardware Used
Arduino microcontroller board

8 LEDs

4 tactile push switches

Current-limiting and pull-down resistors

Breadboard and jumper wires
